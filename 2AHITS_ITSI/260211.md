# Grep

# Pipe

Mit `Pipe = |` kann man befehle kombinireren und das unedlich lang. Das heißt das man damit Bearbeitungsketten bauen kann:

```
~/workspace$ cat klassenkassa.csv  |  head | grep Werkstatt
Sophia,22.09.2023,15.0,Werkstatt
Lena,18.09.2023,13.0,Werkstatt
Emma,22.09.2023,42.0,Werkstatt
Nico,18.09.2023,23.0,Werkstatt
```

# tr

~/workspace$ echo babbababba | tr a x
