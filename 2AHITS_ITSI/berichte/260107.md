## Ablauf von Replit auf Github

1. Am Anfang haben wir uns auf Github einen Account erstellt.
2. Danach haben wir einen Repositories erstellt.
3. Dan haben wir uns auf Replit unter `Git` mit unserem Github Account angemeldet und einen Link/ haben  `Erster Commit` reingeschrieben und haben das ganze Synchroniziert.
4. Damit wurde alles was wir auf Replit hatten, Datein usw. auf Github rüber kopiert.
5. Dan sind wir auf Github unter `Settings` reingegangen und haben unter `Pages` bei `Branchen` von `None` auf `main` umgestellt.
6. Dann konnte man unter `Actions` sehen was grade läuft/heruntergeladen wird. Also jedes mal wenn man was neues Commitet kommt da was neues.
7. Zum Berichte abgeben muss man unter `Settings` dan unter `Pages` und den ganz oberen Link kopieren und auf einer neuen Seite einfügen. Damit der Bericht drinnen ist muss man auf Github gehen und dan auf den Bericht den man zuerst Commiten muss damit alles auf den neusten stand ist und dan das kopieren was ganz oben steht und den teil dan zum Link den du auf der Seite eingefügt hast das zu hinzufügen.
