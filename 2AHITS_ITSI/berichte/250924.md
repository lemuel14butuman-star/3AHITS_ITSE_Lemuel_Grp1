# Grundlagen der Linux Shell

Shell = textortierte Schnittstelle zu einem Betriebssystem (Kermel)

Anzeige in der Konsole: Prompt die Eingabe folgt nachdem Prompt

Bsp. der Befehl `date` 

```sh
$ date
```

Ausgabe des Befehls date: 

```
Wed Sep 24 07:12:52 AM UTC 2025
```

Befehle können Opt. Haben, diese werden mit `-`angegeben.

z.b.

```sh
$ date -I
```
Ausgabe für den Befehel ist:

```
2025-09-24
```

Optionen aus einem  Buchstaben = shortband


longhanf mit 2x `--`:

```sh
$ date --iso-8601
```

Mehr Infos zu einem Befehl

- KI
- Die Option `--help`

```sh
$ date --help
```

- man pages

```sh
$ man date
```

nicht in Replit aber man kann mit dem Text `man date`im Internet suchen.
