# Übung(Befehle - Bewegen und Kopieren)

Der Befehl:
```sh
rmdir
``` 
beudetet das man damit ein verzeichnis lösche wenn es leer ist!

z.B.
```
~/workspace$ rmdir abcd/second_dir/
```



Der Befehl:
```sh
rm und name der datei
```
bedeutet das man damit eine Datei löscht!

z.B.
```
rm abcd/second_dir/xyz.02.3.txt 
```

Mit diesen zwei befehelen `( rmdir und rm )`
hab ich jetzt die Datein die ich vorher angelegt habe gelöscht

```
~/workspace$ tree
.
├── berichte
│   ├── 250910.md
│   ├── 250924.md
│   ├── 251008.md
│   ├── 251022.md
│   ├── img
│   │   └── image.png
│   └── _Lemuel_Butuman.md
└── README.md

2 directories, 7 files
```

----------------------------------------------

Der befehl `cp` = `copy` wird verwendet um Dateien und Verzeichnisse zu kopieren (mit `cp -r` oder `cp -R` kann man ganze verzeichnisse kopieren).

```
~/workspace$ rmdir Copy1
rmdir: failed to remove 'Copy1': No such file or directory
~/workspace$ mkdir Copy_1
~/workspace$ mkdir Copy_2
~/workspace$ cd Copy_1
~/workspace/Copy_1$ touch Test_1
~/workspace/Copy_1$ cp Test_1 Test_2
~/workspace/Copy_1$ tree
.
├── Test_1
└── Test_2

0 directories, 2 files
```

Der befehl `mv` = `move` wird verwendet um Dateien und Verzeichnisse zu verschieben oder umzubenennen. 

```
~/workspace/Copy_1$ mv Test_1 Move_1/
~/workspace/Copy_1$ tree
.
├── Move_1
│   └── Test_1
└── Test_2

1 directory, 2 files
```
