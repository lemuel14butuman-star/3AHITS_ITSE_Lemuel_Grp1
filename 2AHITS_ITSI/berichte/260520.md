## wc

``` 
~/workspace$ wc klassenkassa.csv 
 146  146 4384 klassenkassa.csv
```
wc gibt die Zeile aus, wie viele Buchstaben da drinnen sind usw. 

Damit es leichter wird und du nur die zeile willst dan:
```
~/workspace$ wc -l klassenkassa.csv 
146 klassenkassa.csv
```

## sed

mit `sed` kannst du ganz einfach namen oder sonstiges verändern z.b.

```
~/workspace$ echo "hello there" | sed "s/hello/hi/"
hi there
```
hier wird "hello there" durch "hi there" versetzt

oder in der Datei

