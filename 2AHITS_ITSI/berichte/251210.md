# Übungen head

**1.** 

Bestimmte Zeilen von einer Datei anzeigen geht mit `head -n x=(Zeilen wie viele man ausgeben will) text3.txt=(Dateiname)`. 

z.B.

```
~/workspace$ head -n 5 /etc/passwd
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
bin:x:2:2:bin:/bin:/usr/sbin/nologin
sys:x:3:3:sys:/dev:/usr/sbin/nologin
sync:x:4:65534:sync:/bin:/bin/sync
```
oder 
```
~/workspace$ head -n 7 /etc/group
root:x:0:
daemon:x:1:
bin:x:2:
sys:x:3:
adm:x:4:
tty:x:5:
disk:x:6:
```

**2.**

Wenn eine negative zahl bei head steht also: `head -8 /etc/group` dan werden nur die ersten 5 Zeilen ausgegeben:

```
~/workspace$ head -8 /etc/group

daemon:x:1:
bin:x:2:
sys:x:3:
adm:x:4:
tty:x:5:
disk:x:6:
lp:x:7:
```

**4**

Die ersten 7 Zeilen der Datei `text.txt` in der Datei `anfang.txt` zu übertragen muss man volgendes eingeben `head -7 text.txt > anfang.txt` wie hier zum Beispiel: 

```
~/workspace$ head -7 text.txt > anfang.txt 
~/workspace$ head anfang.txt

2

4

~/workspace$ 
```

**7** 

Hier wird mit `seq -s _ 1 30` also die zahlen von 1-30 mit einem `_` getrennt werden. Dan wird das in einer Datei namens `zahlen2.txt` eingefügt und ausgegeben mit `seq -s _ 1 30 > zahlen2.txt` :
