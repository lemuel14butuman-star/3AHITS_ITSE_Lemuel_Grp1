# Was kann man alles mit dem befehl `Cat` machen ? 


**Nur 'Cat' eingabe:**

Wenn man den Befehl `cat` alleine eingibt kann man in der nächsten Zeile was eingeben das dan wieder ausgegeben wird. 

z.B.

```
~/workspace$ cat
xyz
xyz
a
a
1+2=
1+2=

```

**Wenn man `Cat > File Name` eingibt:**

Wenn man den befehl `cat > File name` eingibt wird ein File erstellt. Nach dem Befehl kannst in einer weiteren Zeile wieder was eingeben. Das dan im File gespeichert wird und mit dem Befehl `control + c`kansst du da wieder aussteigen. 

```
~/workspace/stdinout$ cat > Mata.txt
a
b
c
^C
~/workspace/stdinout$
```

**oder Man gibt `echo Hallo Welt File Name`**

Da wird alles was dazwischen echo und File Name ist gespeichert.

```
~/workspace/stdinout$ echo Hallo Welt > Mata.txt 
~/workspace/stdinout$ cat Mata.txt 
Hallo Welt
```



**Wenn man 'Cat < File Name' eingibt**

Wenn man den Befehl `cat < File Name` eingibt wird dir ausgegeben was im File drinen ist. Das geht auch nur mit `cat File Name`. 

z.B.

```
~/workspace/stdinout$ cat < Mata.txt 
a
b
c
```

oder 

```
~/workspace/stdinout$ cat Mata.txt 
a
b
c
```

**Wenn man `echo Hallo Welt >>hallo.txt`eingibt:**

Wenn man `echo Hallo Welt >hallo.txt`eingibt wird ja Hallo Welt in hallo.txt gespeichert wenn man jetzt aber danach `echo Hallo 2Welt >hallo.txt` eingibt, dann wird das erste also Hallo Welt durch Hallo 2Welt ersetzt. Wenn man jedoch `echo Hallo Welt >>hallo.txt` eingibt wird es einfach dazu hinzugefügt.

```
~/workspace/stdinout$ echo Hallo 2AHITS >hallo.txt 
~/workspace/stdinout$ cat hallo.txt 
Hallo 2AHITS
~/workspace/stdinout$ echo Hallo Welt >>hallo.txt
~/workspace/stdinout$ cat hallo.txt 
Hallo 2AHITS
Hallo Welt
```

**Mann kann auch den inhalt von 2 Files ausgeben:**

Wenn man `cat hallo.txt  test.txt ` eingibt wird der inhalt von hallo.txt ausgegeben und der inhalt von test.txt. 

```
~/workspace/stdinout$ cat hallo.txt  test.txt 
Hallo 2AHITS
Hallo Welt
xyz
abc
Mata
```

```
~/workspace/stdinout$ echo ' >>> ACHTUNG <<< '
```

# Aufgabe stdin/stdout

**Übung (Kopie mit cat)**

Wenn man `cat name der Datei > name der Datei wo der inhalt der vorherigen datein rein kopiert werden soll`
damit kann man von einer Datein den inhalt in einer anderen Datei übertragen/hinein kopieren. 

```
~/workspace/Test$ cat > test3.txt
mata
ce faci 
^C
~/workspace/Test$ cat test3.txt 
mata
ce faci
~/workspace/Test$ cat test3.txt > test4.txt 
~/workspace/Test$ cat test4.txt 
mata
ce faci
~/workspace/Test$ 

```
