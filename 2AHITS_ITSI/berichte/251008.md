## History

- `strg e` steht für das Ende des befehls 
- `strg c` für den programm abbruch / befehls abbruch


**Filesystem**:

- `ls= Long Story` listet daten
- `cd= Compact Disc` kann man unter dateinen herum springen
- `pwd= print working directory` zeigt mir in welcher datei ich gerade bin

**Befehle**:

Mit dem Befehl kann man was ausgeben z.b. wie bei der C sprache `printf("Hello wolrd")
```sh
echo
```

Mit diesem Befehl komme ich in meinem vorherigem Ordner wieder zurück
```sh
cd ..
```

Dieser Befehl zeigt mir mein derectoring in lang informationen / genauer
```sh
ls -l
```

```
total 8
drwxr-xr-x 1 runner runner  96 Oct  8 07:26 berichte
-rw-r--r-- 1 runner runner 108 Sep 24 06:52 README.md
```


Dieser zeigt mir alle datein auch die versteckten Datein (versteckte Datein haben immer einen `.` davor)
```sh
ls -a
```

Dieser Befehl legt ein mir unterverzeichnis an
```sh 
mkdir
```

Mit diesem legt man Datein an
```sh
touch
```

Damit kommst du ins wurzelverzeichnis
```sh
cd /
```

`cd` ohne ein argument bringt dich ins home verzeichnis
```sh
cd```

Mit diesem Befehl komme ich ins arbeitsverzeichnis
```sh
cd ~ oder cd /
```

**Befehle mit dem man sachen löschen kann**:

So lösche ich eine Datei
```sh
rm und name der datei
```

So Lösche ich ein verzeichnis, aber nur wenns leer ist 
```sh
rmdir
``` 

Dieser Befehl löscht alles was darunter ist
```sh
rm -r Dateiname
``` 

Damit löscht man alles !
```sh
rm -r /
```

Dieser Listet mir den inhalt des Wurzelverzeichnis an
```sh
ls /
``` 

**Absoluter Pfad**:

Der vollständige Weg von der Wurzel des Dateisystems (dem Startpunkt) bis zur gewünschten Datei oder dem Ordner

**Relativer Pfad**:

Beschreibt den Speicherort einer Datei oder eines Ordners in Bezug auf das aktuelle Arbeitsverzeichnis
